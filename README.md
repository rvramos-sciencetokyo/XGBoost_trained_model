# XGBoost_trained_model
[Official Data Repository]

Description: Trained model using XGBoost with inputs from WRF-Chem simulations in the Kanto Region, Japan


This repository contains the file for the trained XGBoost model in relation to this manuscript: 
- **Title:** Machine learning-based modeling framework for predicting near-surface PM2.5 informed by a chemistry transport model
- **Authors:** Roseanne V. Ramos, Alvin Christopher G. Varquez, Maria Deandra A. Sayson, Zeyu Chen, Ryoga Hiroki, Atsushi Inagaki, Manabu Kanda, Paul T. Griffiths
- **Journal:** Scientific Reports (submitted for review)


Relevant sections of the manuscript associated with this file:
- The subsection "XGBoost model training and feature importance scores" under the Results section of the manuscript describes the contents of the dataframe inputs used to train the model. The predictive skill metrics for the model training are also discussed here.
- The specific processes undertaken in training the model are detailed in the Methods > Regression modeling using XGBoost > Model Training section of the manuscript.

About the trained model: 
- **Dataset:** Contains 12,541,965 feature samples
- **Python Version:** Requires Python 3.10 or higher.
