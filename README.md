# XGBoost_trained_model
Official Data Repository: Trained model using XGBoost with inputs from WRF-Chem simulations in the Kanto Region, Japan



This repository contains the file corresponding to the trained XGBoost model for the manuscript:
> Paper Title: Machine learning-based modeling framework for predicting near-surface PM2.5 informed by a chemistry transport model
> *Authors: Roseanne V. Ramos, Alvin Christopher G. Varquez, Maria Deandra A. Sayson, Zeyu Chen, Ryoga Hiroki, Atsushi Inagaki, Manabu Kanda, Paul T. Griffiths
  
> (Submitted to Scientific Reports journal)

The subsection "XGBoost model training and feature importance scores" under the Results section of the manuscript describes the contents of the dataframe inputs used to train the model.
The predictive skill metrics for the model training are also discussed here.

The specific processes undertaken in training the model are detailed in the Methods > Regression modeling using XGBoost > Model Training section of the manuscript.
